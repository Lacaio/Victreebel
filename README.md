What I am trying to accomplish here is to reduce the time I spent working in my job by having it handled by this little Bot. This little machine will receive an image screenshot into a folder and have it be processed and turn the query of clients into readable text and then processed by an LLM to choose between many pre written responses I have made.

What Victreebel does in essence is receive the most basic of tickets, process them into a form where an LLM can handle it without any major hassle.

I had initially proposed to forward images to the LLM and have it make up it own responses, but that would just be to reckless in the current state we are in.
